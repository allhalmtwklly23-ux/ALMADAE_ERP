# خريطة الوحدات — مسودة المرحلة B

**الحالة:** مسودة للمراجعة والاعتماد  
**المرجع:** [معمارية النظام](./SYSTEM_ARCHITECTURE.md)

## النواة المؤسسية

| المجال | المسؤولية | يعتمد عليه |
|---|---|---|
| الهوية والعضويات | مستخدم، جلسة، منشأة نشطة، عضوية وحالة الحساب | جميع الوحدات |
| الهيكل التنظيمي | مجموعات، شركات، فروع، وحدات تنظيمية وعلاقات مؤرخة | الموظفون، الصلاحيات، الموافقات |
| الوظائف والتعيينات | الشخص، حساب المستخدم، المنصب، المسمى والتعيين | HRM، المسؤوليات |
| الصلاحيات والسياسات | RBAC/ABAC، نطاق البيانات، حدود الإجراء وفصل المهام | كل API وعملية |
| سير العمل والتفويض | خطوات الموافقة، البدائل، المهلة والتصعيد | المالية والمشتريات والمبيعات |
| التدقيق والإشعارات | سجل التغيير والتنبيه والتسليم | جميع المجالات |
| الوثائق والتكاملات | بيانات الوثائق ومراجع الأسرار وتكاملات الأنظمة | الوحدات ذات الصلة |

## وحدات الأعمال

| المجموعة | الوحدات | الاعتماد الأساسي |
|---|---|---|
| المالية | دليل الحسابات، القيود، الأستاذ، الذمم، الصندوق، الضرائب، الأصول | الهوية، السياسات، مراكز التكلفة |
| التجارة | CRM، عروض وطلبات البيع، الفواتير، المرتجعات، التحصيل، التسويق وخدمة العملاء | العملاء، المنتجات، الأسعار والضرائب |
| الإمداد | الموردون، المشتريات، الاستلام، المخزون، المستودعات، التحويل والجرد | المنتجات، المواقع، الموافقات |
| التشغيل | الإنتاج، الجودة، الصيانة، اللوجستيات، الأصول، المشاريع والعقود | المخزون، التكاليف، الوثائق |
| الموارد البشرية | ملفات الموظفين، العقود، الحضور، الإجازات، الرواتب والأداء | الهيكل والتعيينات والصلاحيات |
| المؤسسة والتحليلات | التواصل، الأوامر، المهام، التقارير، المعرفة وطبقة AI | الصلاحيات والتدقيق ومصادر البيانات |
| الميدان | المناطق، المندوبون، الزيارات، الموقع والطلبات الميدانية | العملاء، التعيينات، الموافقة والخصوصية |

## ترتيب الاعتماد المقترح

الهوية/المنشآت ← التنظيم والتعيينات ← الصلاحيات/التدقيق ← محرك العمليات والموافقات ← المخزون والمبيعات والمشتريات ← المحاسبة والترحيل المتكامل ← HRM وبقية الوحدات ← الميدان ← التحليلات وAI.

لا تعني الخريطة أن كل وحدة منفذة. الحالة الحالية وواجهات CRUD والتطبيقات المخططة موثقة في [تقرير التدقيق](./PROJECT_AUDIT.md). يجب وسم كل ميزة في الكتالوج بأنها فعالة أو تجريبية أو مخططة، وعدم ربطها برابط يوحي باكتمالها.

## حدود المسؤولية

- CRM يملك بيانات العلاقة والتفاعل؛ المبيعات تملك عروض البيع والفواتير.
- المخزون يملك الكميات والحركات؛ لا تعدل وحدة المبيعات الرصيد مباشرة.
- المحاسبة تملك القيود والأرصدة؛ تعرض وحدات الأعمال المستندات المصدرية ولا تنشئ دفتر أستاذ موازياً.
- HRM يملك بيانات الشخص الوظيفية، بينما الحساب والصلاحيات والعضوية ضمن النواة.
- التقارير وAI للقراءة والتحليل ضمن صلاحيات المصدر، ولا تعتمد أو ترحل عمليات حساسة.

## عناصر مفتوحة للاعتماد

1. ترتيب أول وحدات الأعمال بعد تثبيت النواة.
2. هل POS ضمن أول إصدار مستقل أم قناة للمبيعات؟
3. حدود مستندات CRM التي تملكها المبيعات أو خدمة العملاء.
4. هل تخطيط الإنتاج والمخزون متعدد المواقع مطلوبان في أول عميل؟
5. ما الوحدات التي يجب أن تكون قابلة للتفعيل/الترخيص على مستوى المنشأة؟
